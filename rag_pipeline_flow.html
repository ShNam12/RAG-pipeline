Tiếp nhận & API

Logic
Mở kết nối Server-Sent Events (SSE) với người dùng. Nhận câu hỏi, gọi RAGService và stream token trả về. Gói metadata đánh giá (latency, top 10 docs) vào cuối luồng.
Tech Stack

Điều phối & Nhúng (Embedding)

Logic
RAGService đóng vai trò nhạc trưởng. Đo đạc độ trễ (latency). Nhúng (embed) câu truy vấn của người dùng thành vector để chuẩn bị tìm kiếm trong không gian vector.

Truy xuất đa luồng (Retrieval)

Logic
Sử dụng Qdrant để tìm kiếm HNSW song song hoặc tuần tự: một luồng lấy text thông thường (must_not level=2) và một luồng lấy bảng biểu (level=2). Chuyển JSON về object SearchCandidate.
Tech Stack
QdrantClient HNSW Vector Search Pydantic

src/rag1/retrival/searcher.py
4

Gộp kết quả (RRF Fusion)

Logic
Sử dụng thuật toán Reciprocal Rank Fusion (k=60) để gộp danh sách chunk văn bản và chunk bảng. Loại bỏ trùng lặp (dedup_key theo source_id và text). Chuẩn hóa điểm mà không phụ thuộc vào Cosine thuần.
Tech Stack
RRF Algorithm Set/Hash Maps
Code Location
src/rag1/retrival/fusion.py
5

Xếp hạng lại (Reranking)

Logic
Dùng mô hình Cross-Encoder để chấm điểm lại mức độ liên quan giữa Query và Candidate. Load model dạng lazy (tránh ngốn RAM lúc khởi động). Có cơ chế fallback: nếu sập VRAM, vẫn trả về kết quả RRF trước đó.
Tech Stack
BGE-M3 CrossEncoder PyTorch / GPU Fault Tolerance
Code Location
src/rag1/retrival/reranker.py
6

Tổng hợp & Stream (LLM)

Logic
Đưa Top K chunks vào prompt. Xử lý format đặc biệt cho bảng (Markdown/HTML). Gửi prompt đến LLM, nhận response dạng stream. Thu thập tổng thời gian và điểm số gửi trả lại Client.
Tech Stack
